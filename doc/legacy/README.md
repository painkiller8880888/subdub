# Legacy documents

このディレクトリは、過去の実装計画、廃止済み仕様、移行前の設計、Issue・PR に対応した判断を確認するための履歴資料を置く場所です。

配下の文書は現在の正本ではありません。新規実装の仕様根拠、現在の実装要件、実装順序、未実装判定の根拠として使用しないでください。

現在の正本は次の 2 文書です。

- [`../doc.md`](../doc.md) — 要求、目的、機能、ユーザー体験、製品仕様
- [`../implementation-spec.md`](../implementation-spec.md) — データモデル、API、保存、validation、アーキテクチャ、実装詳細

legacy 文書は、過去の Issue、PR、migration、設計判断の背景を調査するときだけ参照します。legacy 文書と現在の正本が矛盾する場合は、現在の正本を優先します。
